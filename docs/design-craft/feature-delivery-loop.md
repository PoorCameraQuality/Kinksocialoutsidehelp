# Feature delivery loop (internal process note)

This project sometimes uses a structured backlog loop: audit, plan, implement, test, UX pass, then docs.

That automation lives in the private development workspace. It is not required to review auth, privacy, or product code in this repository.

For reviewers: prefer the normal path in [TESTING.md](../TESTING.md) and [ENGINEERING_REVIEW_CHECKLIST.md](../ENGINEERING_REVIEW_CHECKLIST.md).
